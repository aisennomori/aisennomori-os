唱え方リスト 真言のように連続して唱える順

宣言の共通型（多くの件がこれを共有し、名だけ差し替える）：

「偉大なる○○様に帰依します。お力をお貸しください。私の心に、あなたの神通力を注いで下さい。そして、私にとって必要な事が起きるように援助をお願いします。」 ※レムリア・西洋系は「私のハートに、あなたのエナジーを」「サポートをお願いします」の言い回し。

並びは系統順（仏教系→神道系→福徳系→レムリア・西洋系→龍・統合系）。順番自体はマニュアル指定ではなく、唱える順は自由に組み替えてよい。印の形そのものは文章・写真で示されているものが多いため、ここでは「どの印か」までとし、形の確認は原典で。

仏教系

  1. 大日如来：般若心経（題目→本文2回→「羯諦羯諦…」から最後までもう1回）→ 金剛界の印を組み、金剛界マントラ「おん あびらうんけん ばさらだとばん」×7回 → 宣言（「ああ、偉大な大日如来様に帰依します」＋ハート／エナジー版）
  2. 弥勒如来：合掌して一礼 → 弥勒如来印を組み「オン マイタレイヤ ソワカー」×21回 → 合掌に戻し一礼 → 宣言
  3. 薬師瑠璃光如来：薬壺印を組み「オン コロコロ センダリ マトウギ ソワカ」×7回 → 「薬師瑠璃光如来様」×3回 → 宣言
  4. 不動明王：般若心経（大日如来と同じ唱え方）→ 手印を組み、心咒「のうまくさーまんだー ばーざらだん せんだーまーかろ しゃーだーそわたや うんたらたーかんまん」×7回 → 宣言（「ああ、偉大な不動明王様に帰依します」）
  5. 毘沙門天：印（2種のどちらでも可）を組み、光明真言「おんあぼきゃー べいろしゃのー まかぼだらー まにはんどば じんばら はらばりたや うん」×7回 → 毘沙門天真言「なうまくさんまんだー ぼだなん べいしらまんだや そわかー」×7回 → 宣言
  6. 千手観世音菩薩：合掌して一礼 → 専用手印（人差し指と薬指を交差させる印）を組み「オン バサラー タラマー キリーク」×21回 → 合掌に戻し一礼 → 宣言
  7. 観世音菩薩：印を組み、聖観音真言「オン アロリキャ ソワカ」×7回 → 宣言（導入が独特：「全ての世界の衆生に救いの手を差し伸べます、観世音菩薩様に帰依します…」）

神道・日本の神々

  1. 天之御中主神：二礼二拍手・合掌 → 神通秘詞を奏上 → 二礼二拍手一礼 → 「天之御中主神様」×3回＋宣言
  2. 造化三神様：六礼六拍手・合掌 → 大元造化三神報恩之祈詞を天に向かって奏上 → 三柱の名を呼び宣言。締め：「天御中主之大御神 咲きはへ／高皇産靈之大御神 咲きはへ／神皇産靈之大御神 咲きはへ」＋「神ながらたまちはえませ」×3 → 六礼六拍手三礼
  3. 天照大御神：手を洗い口を漱ぐ → 二礼二拍手 → 「あーめーのーおーきー つーちーのーおーきー あーめーのーひーれー つーちーのーひーれー」→ 十言の神咒「アーマーテーラースー オーオーミーカーミー」×10回 → 印（天乃咲手印／八咫鏡印のどちらか）を組んで宣言 → 二拍手一礼
  4. 伊耶那岐命・伊耶那美命：二礼二拍手・合掌 → 「伊耶那岐命様・伊耶那美命様」×3回＋宣言（参考として二柱それぞれの祝詞＝祓詞ほかが併記されている）
  5. 宇迦之御霊神：二礼・合掌 → 稲荷祝詞（本詞／略詞）を奏上 → 二礼二拍手一礼 → 「宇迦之御霊神様」×3回＋宣言
  6. 木花咲耶姫命：事前浄化（入浴・塩うがい・手洗い）→ 二礼二拍手 → 富士の浅間大神への祝詞を奏上 → 「木花咲耶姫命様（コノハナサクヤヒメノミコト様）」×3回＋宣言 → 二拍手一礼
  7. 瀬織津姫：事前浄化（入浴・塩うがい・手洗い）→ 二礼二拍手一礼 → 「瀬織津姫 饒速日尊（ニギハヤヒノミコト）」をマントラのように×3回＋宣言 → 終わりも二礼二拍手一礼
  8. 菊理媛神命：事前浄化（塩風呂・塩水うがい等）→ 二礼二拍手 → 龍神祝詞を奏上 → 二拍手一礼 → 「菊理媛神命様（くくりひめかみのみこと様）」×3回＋宣言

福徳系

  1. 七福神：手印なし・合掌のみ。合掌して一礼 → 七柱の真言を各×7回（毘沙門天「オン ベイシラマンダヤ ソワカ」／大黒天「オン マカキャラヤー ソワカ」／弁財天「オン ソラソバティエー ソワカ」／恵比寿天「オン インダラヤー ソワカ」／福禄寿「オン マカシリ ソワカ」／寿老人「オン バサラユセイ ソワカ」／布袋尊「オン マイタレイヤ ソワカ」）→ 一礼して宣言 → 締め「七福神集結 開運招福・無病息災・延命長寿 オン ロキャロキャ キャラヤー ソワカ」×7回
  2. 大辯財天：印相を組み「オン ソラソバティエイ ソワカ」×7回 → 宣言（「ああ、偉大なる大辯財天様に帰依します」※原典は「様様」の二重表記）

レムリア・西洋系

  1. マザー・メアリー：宣言のみ。「マザー・メアリー様」×3回＋「私に力をお貸しください…」（イメージ：頭上から金色の光、ハートがピンクに輝く）※要約カード由来のため宣言は要点のみ
  2. イエスと二人のマリア：宣言のみ。「イエスキリスト様・聖母マリア様・マグダラのマリア様。私に力をお貸しください…」
  3. サナトクマラ：「マスター・サナトクマラ ホワイトブラザーフッド」×3回＋宣言
  4. 尊天：合掌して尊天真言「オン バサラー ダルマキリー ベイシラマナヤー ダルマハラー マソバミウン ソワカー」×7回 → 合掌を解いて宣言（宛名は「護法魔王尊様・千手観世音菩薩様・毘沙門天王様」の三者連名）
  5. レディー・レムリア：宣言のみ。「レディー・レムリア様」×3回＋宣言

龍・統合系

  1. 虹龍と鳳凰：事前浄化（塩風呂・塩水うがい）→ 虹龍の手印を結び「オン メイキャシャ ニエイ ソワカ」×7回 → 鳳凰の手印を結び「オン ガルダヤ ソワカ」×7回 → 印を解き「虹龍様・鳳凰様」×3回＋宣言
