# G検定 学習ツール 操作マニュアル

3つのアプリの使い方をまとめています。すべてブラウザだけで動きます。

---

## はじめに：3つの役割

| | 使う場面 | 何をするか |
|---|---|---|
| **100問アプリ** | まとまった学習時間 | 問題を解く・実力を測る・間違いを見返す |
| **用語集** | 迷ったとき | 調べる・2つの違いを確かめる |
| **瞬殺トレーニング** | すきま時間・試験直前 | 反射で答えられるようにする |

迷ったら **瞬殺 → 用語集 → Web/AI** の順に進むのが速いです。

---

## 100問アプリ（gkentei-100q.html）

### 全体の流れ

ホーム画面には **学習進捗**（全体・技術分野・法律倫理分野）が3本のバーで出ます。

### 通常の演習

1. **出題順**を選ぶ … 順番通り／ランダム
2. **採点方式**を選ぶ … 1問ずつ採点／テストモード
3. **学習モード**を選ぶ … 10問／20問／50問／100問／間違えた問題／未回答問題／苦手問題／技術分野／法律・倫理分野／シラバス別

**1問ずつ採点** … 選択肢をタップ →「回答する」→ 正誤と解説
**テストモード** … 選択肢をタップするだけで次へ進む。全問終えてからまとめて採点

出題中はタイトルとシラバスIDが隠れています。タイトルが正解語そのものになっている問題があるためです。採点後に表示されます。

### 実戦テスト

ホームの紫色のカードから「実戦テストへ」。

1. **セットを選ぶ** … 第1セット30問／第2セット30問。それぞれ受験状況と初見正答率が出ます
2. **出題数**を選ぶ … 10問／20問／30問
3. **出題範囲**を選ぶ … すべての問題／未出題だけ
4. 「テストを開始」

テスト中は正誤も解説も出ません。選択肢と出題順はシャッフルされます。前へ戻って解答を変更できます。

**最後の問題で「採点する」を押すと確定します。**

結果画面では、正答率・所要時間・平均回答時間・**シラバス別の正答率**（60%未満は赤字）・解答一覧が出ます。行をタップすればその問題の解説が開きます。

### 間違えた問題を見返す

実戦テストのセット選択画面 →「間違えた問題を見返す」。

一度でも間違えた問題が蓄積されます。フィルターで絞り込めます。

| フィルター | 内容 |
|---|---|
| すべて | 一度でも誤答した問題 |
| 現在も不正解 | 直近の解答が不正解 |
| 過去に誤答あり | 今は正解できている |
| **初見誤答のみ** | 最初に解いたとき間違えた問題 |
| 第1セット／第2セット | セット別 |
| 技術／法律・倫理 | 分野別 |

**「初見誤答のみ」は解き直して正解しても消えません。** 最初に理解できていなかった論点が永続的に残るので、弱点分析に使えます。

各問題の詳細画面では、自分の回答・正解・解説に加えて、**関連する既存100問へ直接ジャンプ**できます。「この問題をもう一度解く」で1問だけ再挑戦することもできます。

### 注意点

**中断すると、表示済みの問題は初見として消費されます。** 初見正答率を正確に測りたい場合は、通しで最後まで解いてください。

## 用語集（gkentei-yougo.html）

437語を収録しています。

### 基本の検索

検索欄に用語を入れると、章見出しが消えて**検索結果だけ**が縦に並びます。同じ用語が複数の章にある場合は1枚にまとめられます。

### 2語検索が本領です

**迷った2択をそのままスペース区切りで入れてください。**

```
適合率 再現率
営業秘密 限定提供データ
匿名加工 仮名加工
請負 準委任
```

一致度の高い順に並ぶので、**上位1〜2件に決定打が出ます**。

### 比較チップ

検索欄の下に、よく迷う比較が10個並んでいます。タップするだけで検索が走ります。

```
勾配消失 vs 勾配爆発 ／ L1 vs L2 ／ 多クラス vs 多ラベル
セマンティック vs インスタンス ／ GAN vs VAE vs 拡散
適合率 vs 再現率 ／ 転移学習 vs 破滅的忘却
匿名加工 vs 仮名加工 ／ 請負 vs 準委任 ／ 新規性 vs 進歩性
```

検索を始めるとチップは自動的に隠れます。「クリア」で戻ります。

### 見つからないとき

検索欄の横に3つのボタンがあります。

| ボタン | 用途 |
|---|---|
| 🌐 Web | 通常のGoogle検索 |
| ✨ AI | Google AIモード（続けて質問できる） |
| 公式 | 該当する省庁・委員会に絞った検索 |

**AIへ渡すときは、判断軸を自分で示すと精度が上がります。**

```
見逃しを減らしたい場合は適合率と再現率のどちらを重視？理由も一言
```

問題を丸ごと解かせるより、**2択まで絞ったあとの決定打確認**に使うほうが有効です。

なお、AIの回答は法令や制度の細部で誤ることがあります。30条の4の例外、仮名加工情報の第三者提供可否、PoC段階の契約類型などは、**公式ボタンを併用**してください。

### その他の機能

**表示切替** … 試験重視（ひとこと＋キーワード）／全情報（教科書の説明も表示）
**暗記モード** … 説明を隠して用語だけ表示
**記憶状況** … 各カードの丸印をタップして「要確認」「記憶済」を記録
**比較モード** … 25組の比較セットを一覧

## 瞬殺トレーニング（gkentei-flash.html）

26論点を反射で答えられるようにするツールです。**1セット20問、3〜4分**で終わります。

### 使い方

1. **「全カード（26）」**または**「弱点だけ」**を選ぶ
2. 4択が出るので**タップするだけ**（確定ボタンはありません）
3. すぐに判定と決定打が出る
4. 「次へ」で進む

### 5秒と10秒が基準です

答えるまでの時間で、カードが5つの状態に分かれます。

| 状態 | 条件 |
|---|---|
| **弱点** | 間違えた |
| **要反射** | まだ解いていない、または10秒を超えて正解 |
| **理解済み** | 5〜10秒で正解 |
| **定着候補** | 5秒以内で正解（1回目） |
| **定着確認済み** | 5秒以内の正解が2回連続 |

**5秒を超えると `streak` がリセットされます。** 正解でも12秒かかっていれば反射にはなっていないためです。

ホーム画面に5つの数が出るので、進み具合が分かります。「弱点だけ」を選ぶと、**定着確認済み以外**が出題されます。

### 結果の見方

正答率だけでなく、速度別に2つの枠が出ます。

**要反射（10秒超で正解）** … 最優先で潰す対象です。知ってはいるが取り出すのに時間がかかっています。

**理解済み（5〜10秒で正解）** … 意味は分かっています。あと少しで反射になります。

この2つが、次に何をすべきかをそのまま示しています。

### 用語集へ飛ぶ

判定画面の「用語集で〜を見る」を押すと、**その論点で検索した状態の用語集**が別タブで開きます。決定打だけでは足りないときに使ってください。

### A4シートを印刷する

ホーム下部の「A4瞬殺シートを表示」→「印刷する」。

**3ページ**に26論点すべてが収まります。白黒印刷を想定しており、**★＝仲間外れ、太字＝決定打**で意味が伝わるようにしています。

試験前に2〜3分で全体を見返せる分量です。

## GitHub Pagesへの配置

1. GitHub Desktopで3ファイルを差し替える
2. Summary を入力して **Commit to main**
3. **Push origin**（ここを忘れるとサイトに反映されません）

配置後のURLは次のようになります。

```
https://（ユーザー名）.github.io/（リポジトリ名）/gkentei-100q.html
https://（ユーザー名）.github.io/（リポジトリ名）/gkentei-yougo.html
https://（ユーザー名）.github.io/（リポジトリ名）/gkentei-flash.html
```

**3ファイルは同じ階層に置いてください。** 瞬殺トレーニングから用語集へのリンクが相対パスのためです。

## 学習履歴について

履歴は**端末とブラウザごと**に保存されます（localStorage）。

- 別の端末では引き継がれません
- **プライベートブラウズでは、タブを閉じると消えます**
- ブラウザのデータを消去すると失われます

4つのキーに分かれており、互いに影響しません。

```
gkentei_100q_v1        既存100問
gkentei_practical_v1   実戦テスト
gkentei_yougo_status_v1 用語集の記憶状況
gkentei_flash_v1       瞬殺トレーニング
```

リセットは各アプリの設定画面から、系統ごとに個別に実行できます。

---

## 困ったとき

**履歴が消えた**
別のブラウザで開いていないか、プライベートブラウズでないかを確認してください。100問アプリの設定画面に復元ボタンが出ている場合は、第1セットの初回結果だけ復元できます。

**用語集で目的の語が出ない**
2語をスペース区切りで入れてみてください。それでも出ない場合は教材に収録されていない可能性があります。🌐 Web か ✨ AI を使ってください。

**「一部の語しか一致しませんでした」と出る**
未一致の語が教材にありません。この表示が繰り返し出る語は、教材への追加候補になります。

**瞬殺トレーニングで用語集へ飛べない**
3ファイルが同じ階層にあるか確認してください。
