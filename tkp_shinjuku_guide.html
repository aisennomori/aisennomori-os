品川で降りずに東京駅へ
→ 山手線で神田駅「北口」

本編（品川 ⇄ 新宿 ⇄ TKP）はそのままです。こちらは品川で降りずに神田駅 北口へ向かう場合だけの別ルート。
品川までは本編とまったく同じ電車。降りずに1駅先の東京駅まで乗って、山手線で神田へ1駅です。

START：岐阜羽島（本編と同じ電車） GOAL：神田駅 北口
A

品川から先の分は、東京駅で精算

スマートEX
POINTスマートEXには「東京都区内」がありません

窓口で買う紙のきっぷなら「東京都区内」というゾーンで発券され、神田まで追加なしで行けます。ただしスマートEXはこの特定都区市内制度が適用外で、予約した区間（＝品川まで）を超えた分は別途かかります。

とはいえ手続きは簡単です。予約はそのままで乗って、東京駅で乗り越し精算するのがいちばん確実で、当日の段取りもシンプルになります。

① 予約はそのまま。いつも通り岐阜羽島から乗る
品川までの予約のままで問題ありません。乗車前に何かしておく必要はないので、当日は普段どおり改札を通ってください。
② 東京駅では、自動改札ではなく「有人通路」へ
新幹線のりかえ口の脇にある、駅員さんが立っている通路に並びます。最初からこちらへ向かえば、自動改札で戸惑う時間がありません。乗り越しはごく日常的な手続きなので、気を遣う必要はまったくありません。
そのまま使える言い方「スマートEXで品川までの予約ですが、東京まで乗り越しました。精算をお願いします。」
③ 支払うのは「品川〜東京の運賃ぶん」だけ
東海道新幹線は東京駅と品川駅で特急料金が同額です。自由席なので特急料金は変わらず、差額は品川〜東京の運賃相当分にとどまります。現金でもすぐ済みます。
車掌さんが回ってきたら、その場でもOK
車内で声をかけられたら「品川までの予約ですが、東京まで乗り越します」と伝えれば、その場で手続きできます。ただし今の東海道新幹線は車内改札をほとんど行わないため、誰も来ないのが普通です。待たずに、東京駅での精算を前提にしておいて大丈夫です。
💴 神田までにかかる追加のお金
品川 → 東京（新幹線の乗り越し分）運賃差のみ
東京 → 神田（山手線・1駅）約160円

ICカード（Suica・PASMO等）のチャージだけ、前日までに確認しておくと安心です。東京〜神田ぶんは、そのカードをタッチするだけで済みます。
※2026年3月14日にJR東日本の運賃が改定されています。金額は駅の運賃表でご確認ください。

B

東京駅で山手線に乗り換える

新幹線 → 山手線
品川（9:35頃）では降りず、そのまま座っている
品川の次は終点・東京です。品川〜東京は約7〜8分。荷物をまとめるのは品川を出てからで十分間に合います。
東京駅で降りたら「JR線のりかえ口」へ
東海道新幹線から在来線への乗換改札は「中央のりかえ口」と「南のりかえ口」の2か所。ひかりの自由席（1〜5号車）からは「南のりかえ口」が近く、8号車より後ろなら「中央のりかえ口」が近いです。改札を出ずに在来線へ移動できます。
のりかえ口では有人通路へ（Aの精算）
駅員さんのいる通路で精算を済ませ、そのまま在来線側へ進みます。ここから先はICカードで在来線あつかいになります。
山手線「内回り（上野・池袋方面）」＝ 4番線ホームへ
緑色の案内が目印です。「品川・渋谷方面」と書かれた5番線は逆方向なので乗らないでください。隣の3番線に来る京浜東北線（大宮方面）も神田に停まるので、先に来たほうで大丈夫です。
🚃 乗車時間：1駅・約2分
C

神田駅に到着・北口を出る

JR神田駅
内回りは「3番線ホーム」（2階）に到着
神田駅は高架のコンパクトな駅で、改札も2か所だけ。新宿駅のような複雑さはありません。ホームから階段・エスカレーター・エレベーターで1階へ下ります。
1階に下りたら「北口・東口」と書かれた改札（＝北改札）を出る
神田駅の改札は「北改札（北口・東口）」と「南改札（西口・南口）」の2つ。改札を出て左が北口、右が東口です。北改札を出たところに東京メトロ銀座線の入口もあります。
【時短メモ】北口改札にいちばん近いドア
山手線内回りは先頭が11号車。北口改札に近いのは9号車の1番ドア（前から3両目）あたりです。東京駅で乗るときに、この位置を狙っておくとスムーズです。
🗺️ 神田駅の構内図で確認したい場合
改札は2か所だけなので迷いにくい駅ですが、出口の位置関係を先に見ておくとより安心です。
JR東日本 神田駅 構内図 ↗

⚠️ 寄り道編で気をつけること
  • 乗る前の準備は不要。予約は品川までのままでかまいません。品川から先は東京駅の有人通路で精算すれば、それで完了です。
  • 品川で改札を出ない。品川で出てしまうと予約はそこで終了し、その先はすべて新しく買い直しになります。
  • 東京駅の山手線は方向に注意。神田へは内回り＝4番線（上野・池袋方面）。5番線（品川・渋谷方面）は本編で使う方向で、こちらでは逆方向です。
  • ICカードのチャージを確認。東京〜神田ぶんはICカードから引き落とされます。
  • 帰りは本編どおり。帰りの新幹線は「品川 18:10発 ひかり655号」のままです。
  • 時間の目安。品川9:35 →（新幹線）→ 東京9:43頃 →（乗換7〜10分）→ 山手線 → 神田10:00前後に到着するイメージです。
⚠️ 迷いやすいポイント
  • 新宿駅は出口が非常に多いが、「西口」「7番出口」だけを意識すれば問題ない
  • 山手線は行きと帰りで方向が逆。行きは「外回り（渋谷・新宿方面）」、帰りは「内回り（原宿・渋谷・品川方面）」を電光掲示板で必ず確認する
  • 地上に迷ったときは、ヨドバシカメラ新宿西口本店の大きな看板を目印にすると分かりやすい

まとめ

【行き】岐阜羽島7:33発「ひかり」（自由席）で品川駅へ（9:35着）。品川駅で山手線（外回り）に乗り換え、新宿駅で西改札方面へ進み、7番出口を目印にTKP新宿西口カンファレンスセンター（カンファレンスルーム9B）へ向かいます。8/29（土）15:30開始、初めて新宿を訪れる方でも迷いにくいルートです。

岐阜羽島 7:33発 → ひかり（自由席） → 品川駅 9:35着 → JR山手線 外回り（渋谷・新宿方面） → 新宿駅 → 西改札方面 → 7番出口 → TKP新宿西口カンファレンスセンター 9B

【帰り】TKPから7番出口方面へ戻り、新宿駅西改札から山手線内回り（原宿・渋谷・品川方面）で品川駅へ。新幹線のりかえ口から新幹線ホームへ向かい、18:10発「ひかり655号」（16号車3番E席）に乗車します。
